# Paper

`ledgerevolve.md` is the project's technical report: what the loop
is, where it sits against prior art, how the metric was learned, what
it does not claim.

Conventions: Markdown source of truth, neutral register, no
poetry. Numbers cited from primary sources (Artificial Analysis pages,
repo READMEs, ledger rows). Prior art stays a positioning section;
elaboration lives in code docs and the Pi ecosystem wiki.
